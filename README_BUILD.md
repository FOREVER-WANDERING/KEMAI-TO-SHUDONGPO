# 蔬东坡订单同步工具 - 构建指南

本文档说明如何将蔬东坡订单同步工具打包成Windows可执行文件(.EXE)。

## 前提条件

- Python 3.6或更高版本
- PyInstaller (`pip install pyinstaller`)
- Pillow (`pip install pillow`)
- 如果要创建安装程序，需要安装Inno Setup 6

## 构建步骤

### 1. 创建图标

运行以下命令创建应用程序图标：

```
python create_icon.py
```

这将创建一个名为`icon.ico`的图标文件。

### 2. 构建可执行文件

运行以下批处理文件构建可执行文件：

```
build_exe.bat
```

这将在`dist\蔬东坡订单同步工具`目录中创建可执行文件及其依赖项。

### 3. 构建安装程序（可选）

如果您希望创建一个安装程序，请先安装Inno Setup 6，然后运行以下批处理文件：

```
build_installer.bat
```

这将在`installer`目录中创建一个安装程序。

## 使用说明

### 直接运行可执行文件

1. 进入`dist\蔬东坡订单同步工具`目录
2. 双击`蔬东坡订单同步工具.exe`运行应用程序

### 使用安装程序

1. 运行`installer\蔬东坡订单同步工具_安装程序.exe`
2. 按照安装向导的指示完成安装
3. 从开始菜单或桌面快捷方式启动应用程序

## 注意事项

- 构建的可执行文件包含所有必要的依赖项，可以在没有安装Python的计算机上运行
- 如果您修改了源代码，需要重新构建可执行文件
- 日志文件将保存在应用程序所在目录的`logs`子目录中

## 故障排除

如果构建过程中遇到问题，请检查以下几点：

1. 确保已安装所有必要的依赖项
2. 确保Python环境变量设置正确
3. 如果使用虚拟环境，确保已激活虚拟环境
4. 检查构建过程中的错误消息

如果问题仍然存在，请联系技术支持。
